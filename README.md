# Projeto Transforme-se

Interface web de autenticação com visual moderno, efeitos holográficos e fundo animado em caracteres ASCII.

## ✨ Funcionalidades e recursos

- Tela de login com campos de usuário e senha.
- Opção para lembrar a senha.
- Links para cadastro e recuperação de senha.
- Fundo animado com gradiente em tons de roxo, rosa e ciano.
- Cartão com efeito holográfico e inclinação 3D que reage ao movimento do cursor e ao toque.
- Layout adaptável para diferentes tamanhos de tela.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Boxicons para os ícones

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Explore a interface e seus efeitos visuais.

> Observação: este projeto apresenta a interface front-end. O código disponível não indica integração com um backend para autenticação real de usuários.
